 # Ebook - A Jornada FrontEnd
> Projeto feito com I.A.s, com o objetivo de aperfeiçoar o conhecimento na área.

## 💻 Tecnologias utilizadas no projeto
🔗 Links
- [ChatGpt](https://chatgpt.com/)
- [PowerPoint](https://powerpoint.cloud.microsoft/pt-br/)
- [Craiyon](https://www.craiyon.com/pt)
- [Google](https://www.google.com/)
- [ShowCode](https://showcode.app/)
- [GIMP](https://www.gimp.org/downloads/)
<br>

## ✨ Como foi feito?
- Conteúdo criado com ChatGpt.
- Ebook feito no PowerPoint.
- Capa gerada no Craiyon.
- Imagem do Escudo HTML, baixada do Google.
- Imagem de código estiloso criada no ShowCode.
- Redimensionamento de imagens, feito no GIMP.
<br>
